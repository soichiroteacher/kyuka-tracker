# 休暇管理アプリ

東京都教職員向けに、年次有給休暇(年休)や看護休暇などの特別休暇の取得記録・残日数(残時間)を管理するローカルWebアプリです。

## 特徴

- サーバー不要。`index.html` をブラウザで開くだけで動作します。
- データはブラウザの localStorage に保存されます(端末・ブラウザごとに独立)。
- 休暇種別・年間付与量・繰越上限は「設定」タブから自由に編集できます。

## 使い方

1. `index.html` をブラウザで開きます(ダブルクリック、または任意の簡易サーバーで配信)。
2. 「設定」タブで、所属先の規程に合わせて休暇種別・付与日数・繰越上限・年度の開始月を確認・調整します。
3. 「ダッシュボード」または「記録一覧」から「＋ 記録を追加」で、休暇を取得した日付・種別・日数(または時間数)を入力します。
4. ダッシュボードで、選択した年度ごとの残日数・残時間が確認できます。

## 初期設定されている休暇種別について

年次有給休暇(20日/年、繰越上限20日)、看護休暇(年40時間)など、一般的な地方公務員・東京都教職員の休暇制度を参考にした目安値を初期値として設定しています。実際の付与日数・時間数・繰越条件は所属の規程・条例と異なる場合があるため、必ず確認のうえ「設定」タブで調整してください。

## データのバックアップ

「設定」タブの「エクスポート(JSON)」でデータをファイルに書き出し、「インポート(JSON)」で復元できます。端末を変える場合やブラウザのデータを消去する前には、エクスポートしておくことをおすすめします。
