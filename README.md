# 休暇管理アプリ

年次有給休暇(年休)や、子の看護休暇などの特別休暇について、取った記録と残りの時間を自分で管理するアプリです。
1人1人が自分の分を記録して使います(ほかの先生の記録は見えません)。

- 休暇はすべて時間で記録し、「〇日〇時間〇分」で表示します(1日 = 7時間45分)。
- 記録は「日」でも「時間」でも入力できます。

## 使い方

1. 校務共有サーバーにある `index.html` を、**Chrome または Edge** で開きます。
2. 初めて使うときは「設定」タブで、休暇の種類・1年に付与される時間・繰り越せる上限・年度の始まりの月を、学校の規程に合わせて確認します。
3. 休暇を取ったら「＋ 記録を追加」で、日付・種類・日数または時間を入力して「保存」します。
4. 「取得と残り」タブ(最初の画面)に、今年度に取った量と残りが種類ごとに表示されます。
5. 年度の途中から使い始めたときは、「取得と残り」のカードにある「付与・繰越を調整」で、その年度の付与量や前年度からの繰り越しを入力します。空欄なら自動で計算し、「標準に戻す」でいつでも戻せます。

初めから入っている休暇の種類と時間は、一般的な目安です。**必ず学校の規程と照らして直してください。**

## データの保存場所

- 記録は、**今使っているパソコンのブラウザの中**(保存領域)にだけ保存されます。共有サーバーやインターネットには送られません。
- そのため、別のパソコンやブラウザで開くと記録は見えません。いつも同じパソコン・同じブラウザで使ってください。

## バックアップと復元

ブラウザのデータを消したり、パソコンが替わったりすると記録が消えます。**月に1回程度、バックアップを取ってください。**

- **バックアップ**:「設定」タブの「データを書き出す(バックアップ)」を押すと、`休暇管理_バックアップ_日付.json` がダウンロードされます。自分のフォルダなど、なくさない場所に保存してください。
- **復元**:「設定」タブの「データを読み込む(復元)」を押し、バックアップのファイルを選びます。確認のメッセージが出たあと、今の記録がバックアップの内容に置き換わります。
- 以前のバックアップ(`kyuka-data-日付.json`)も、同じ方法で読み込めます。

## 困ったとき

| こんなとき | どうする |
|---|---|
| 記録が全部消えている | 別のパソコン・ブラウザで開いていないか確認してください。それでもなければ、バックアップから復元してください。 |
| 「ファイルを読み込めませんでした」と出る | 「データを書き出す(バックアップ)」で作ったファイルを選んでいるか確認してください。 |
| 残りの時間が合わない | 「設定」タブの付与時間・繰越上限、「付与・繰越を調整」の値を確認してください。 |
| 「全データを削除」を押してしまった | 元に戻せません。バックアップから復元してください。 |
