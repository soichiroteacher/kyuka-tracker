# 休暇管理アプリ

東京都教職員向けに、年次有給休暇(年休)や看護休暇などの特別休暇の取得記録・残り時間数を管理するローカルWebアプリです。

## 特徴

- サーバー不要。`index.html` をブラウザで開くだけで動作します。
- データはブラウザの localStorage に保存されます(端末・ブラウザごとに独立)。
- 休暇はすべて1時間単位で記録します。都の勤務時間(1日=7時間45分)を基準に、日数ベースの制度も時間数に換算して管理します。
- 休暇種別・年間付与時間数・繰越上限は「設定」タブから自由に編集できます。
- 休暇種別ごとに「年サイクル(何月始まりで切り替わるか)」を個別設定できます。子の看護休暇・短期の介護休暇は、初期設定で基本設定の年度と別に暦年(1月始まり)で切り替わるようにしています。

## 使い方

1. `index.html` をブラウザで開きます(ダブルクリック、または任意の簡易サーバーで配信)。
2. 「設定」タブで、所属先の規程に合わせて休暇種別・付与時間数・繰越上限・年度の開始月・年サイクルを確認・調整します。
3. 「ダッシュボード」または「記録一覧」から「＋ 記録を追加」で、休暇を取得した日付・種別・時間数(1時間単位)を入力します。
4. ダッシュボード(最初の画面)に、選択した年度の「今年度取得した時間数」と「残り時間数」が種別ごとに表示されます。

## 初期設定されている休暇種別について

年次有給休暇(155時間/年 ≒ 20日、繰越上限155時間)、子の看護休暇(40時間/年)など、一般的な地方公務員・東京都教職員の休暇制度を、都の勤務時間(1日=7時間45分)で時間換算した目安値を初期値として設定しています。実際の付与時間数・繰越条件は所属の規程・条例と異なる場合があるため、必ず確認のうえ「設定」タブで調整してください。

## データのバックアップ

「設定」タブの「エクスポート(JSON)」でデータをファイルに書き出し、「インポート(JSON)」で復元できます。端末を変える場合やブラウザのデータを消去する前には、エクスポートしておくことをおすすめします。

## GitHub公開 + Googleドライブ同期の設定

アプリ本体(コード)をGitHub Pagesなど公開の場所に置きつつ、休暇の記録データ自体は自分のGoogleドライブに保存する構成にする場合の手順です。

### 1. GitHubでアプリを公開する

1. [GitHub](https://github.com/)でアカウントを作成する(未取得の場合)。
2. 新しいリポジトリを作成する(Public)。
3. このフォルダの中身をそのリポジトリにpushする。
4. リポジトリの Settings → Pages で、公開元のブランチ(例: `main`)を指定して有効化する。
5. 発行されたURL(例: `https://<ユーザー名>.github.io/<リポジトリ名>/`)でアプリにアクセスできるようになる。

### 2. Googleドライブ同期用のOAuthクライアントIDを取得する

休暇の記録データは、上記のURLをアプリが作成した1つのJSONファイルとして、利用者自身のGoogleドライブに保存する(`drive.file` スコープ = アプリが作成したファイル以外には一切アクセスしない最小権限)。

1. [Google Cloud Console](https://console.cloud.google.com/)で新しいプロジェクトを作成する。
2. 「APIとサービス」→「ライブラリ」で **Google Drive API** を有効化する。
3. 「APIとサービス」→「OAuth同意画面」を設定する(User Type: 外部、公開ステータス: テスト中のままでOK。自分のGoogleアカウントをテストユーザーに追加する)。
4. 「認証情報」→「認証情報を作成」→「OAuthクライアントID」を選択し、アプリケーションの種類は **ウェブ アプリケーション** を選ぶ。
5. 「承認済みのJavaScript生成元」に、GitHub PagesのURLのオリジン部分(例: `https://<ユーザー名>.github.io`)を追加する。ローカルで動作確認する場合は `http://localhost` も追加する。
6. 作成後に表示される **クライアントID**(`〇〇〇.apps.googleusercontent.com` の形式)をコピーする。

### 3. アプリ側の設定

1. アプリの「設定」タブ →「Googleドライブ同期」で、取得したクライアントIDを貼り付ける。
2. 「Googleドライブに接続」を押し、自分のGoogleアカウントでログイン・許可する。
3. 以降、記録の追加・編集のたびに自動でGoogleドライブ内のファイル(`kyuka-tracker-data.json`)へ保存される。他の端末で同じURLを開いて同じ手順で接続すると、同じデータを引き継げる。
